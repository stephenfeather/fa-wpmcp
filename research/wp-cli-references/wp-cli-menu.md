# wp menu

## Ability API

- `fa-wpmcp/create-menu` — Creates a new menu.
- `fa-wpmcp/delete-menu` — Deletes one or more menus.
- `fa-wpmcp/item-menu` — List, add, and delete items associated with a menu.
- `fa-wpmcp/list-menu` — Gets a list of menus.
- `fa-wpmcp/location-menu` — Assigns, removes, and lists a menu's locations.
