# wp media

## Ability API

- `fa-wpmcp/fix-orientation-media` — Fix image orientation for one or more attachments.
- `fa-wpmcp/image-size-media` — Lists image sizes registered with WordPress.
- `fa-wpmcp/import-media` — Creates attachments from local files or URLs.
- `fa-wpmcp/regenerate-media` — Regenerates thumbnails for one or more attachments.
