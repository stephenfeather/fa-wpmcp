# wp plugin

## Ability API

- `fa-wpmcp/activate-plugin` — Activates one or more plugins.
- `fa-wpmcp/auto-updates-plugin` — Manages plugin auto-updates.
- `fa-wpmcp/deactivate-plugin` — Deactivates one or more plugins.
- `fa-wpmcp/delete-plugin` — Deletes plugin files without deactivating or uninstalling.
- `fa-wpmcp/get-plugin` — Gets details about an installed plugin.
- `fa-wpmcp/install-plugin` — Installs one or more plugins.
- `fa-wpmcp/is-active-plugin` — Checks if a given plugin is active.
- `fa-wpmcp/is-installed-plugin` — Checks if a given plugin is installed.
- `fa-wpmcp/list-plugin` — Gets a list of plugins.
- `fa-wpmcp/path-plugin` — Gets the path to a plugin or to the plugin directory.
- `fa-wpmcp/search-plugin` — Searches the WordPress.org plugin directory.
- `fa-wpmcp/status-plugin` — Reveals the status of one or all plugins.
- `fa-wpmcp/toggle-plugin` — Toggles a plugin's activation state.
- `fa-wpmcp/uninstall-plugin` — Uninstalls one or more plugins.
- `fa-wpmcp/update-plugin` — Updates one or more plugins.
- `fa-wpmcp/verify-checksums-plugin` — Verifies plugin files against WordPress.org's checksums.
