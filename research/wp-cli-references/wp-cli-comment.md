# wp comment

## Ability API

- `fa-wpmcp/approve-comment` — Approves a comment.
- `fa-wpmcp/count-comment` — Counts comments, on whole blog or on a given post.
- `fa-wpmcp/create-comment` — Creates a new comment.
- `fa-wpmcp/delete-comment` — Deletes a comment.
- `fa-wpmcp/exists-comment` — Verifies whether a comment exists.
- `fa-wpmcp/generate-comment` — Generates some number of new dummy comments.
- `fa-wpmcp/get-comment` — Gets the data of a single comment.
- `fa-wpmcp/list-comment` — Gets a list of comments.
- `fa-wpmcp/meta-comment` — Adds, updates, deletes, and lists comment custom fields.
- `fa-wpmcp/recount-comment` — Recalculates the comment_count value for one or more posts.
- `fa-wpmcp/spam-comment` — Marks a comment as spam.
- `fa-wpmcp/status-comment` — Gets the status of a comment.
- `fa-wpmcp/trash-comment` — Trashes a comment.
- `fa-wpmcp/unapprove-comment` — Unapproves a comment.
- `fa-wpmcp/unspam-comment` — Unmarks a comment as spam.
- `fa-wpmcp/untrash-comment` — Untrashes a comment.
- `fa-wpmcp/update-comment` — Updates one or more comments.
