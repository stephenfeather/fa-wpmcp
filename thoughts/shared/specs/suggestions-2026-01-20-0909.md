# Spec Review Findings (Updated)

## Findings

1. **MCP route mismatch**
   - Auth flow shows `/wp-json/fa-wpmcp/v1/mcp` but server config uses `/wp-json/fa-wpmcp/mcp`.
   - This will break clients if not aligned.
   - References: `wp-abilities-plugin-spec.md:829`, `wp-abilities-plugin-spec.md:1766`

2. **MCP server ID inconsistency**
   - Spec lists server ID as `fa-wpmcp`, but config uses `fa-wpmcp-server` and tool registration expects that.
   - References: `wp-abilities-plugin-spec.md:170`, `wp-abilities-plugin-spec.md:1764`, `wp-abilities-plugin-spec.md:1796`

3. **Activity log schema missing `correlation_id`**
   - Later sections require `correlation_id` in logs, but the table schema doesn’t include it.
   - References: `wp-abilities-plugin-spec.md:263`, `wp-abilities-plugin-spec.md:1607`

4. **Permission model conflict**
   - Permission flow uses `manage_options`, while the identity model defines `fa_wpmcp_*` capabilities.
   - Needs a single source of truth or explicit mapping.
   - References: `wp-abilities-plugin-spec.md:217`, `wp-abilities-plugin-spec.md:792`

5. **Error taxonomy mismatch**
   - Error taxonomy defines custom codes (e.g., `authentication_required`), but examples return `rest_forbidden`.
   - Needs standardization or explicit mapping.
   - References: `wp-abilities-plugin-spec.md:842`, `wp-abilities-plugin-spec.md:911`

6. **Rate limit key does not include IP**
   - Rate limiter says per user + IP, but transient key only uses user ID.
   - References: `wp-abilities-plugin-spec.md:146`, `wp-abilities-plugin-spec.md:319`

7. **Action Scheduler dependency not in composer.json**
   - Spec recommends Action Scheduler but dependencies do not include it.
   - References: `wp-abilities-plugin-spec.md:1305`, `wp-abilities-plugin-spec.md:561`

8. **WordPress version matrix contradiction**
   - Minimum version is 6.9, but "Tested Up To" is 6.5.
   - References: `wp-abilities-plugin-spec.md:1482`

9. **Application Password audit logging is implied but unspecified**
   - Spec says passwords are logged to `wp_fa_wpmcp_activity_log`, but no mechanism described.
   - References: `wp-abilities-plugin-spec.md:818`

## Open Questions

1. Should the MCP route be versioned (`/wp-json/fa-wpmcp/v1/mcp`) or unversioned (`/wp-json/fa-wpmcp/mcp`)?
2. Which MCP server ID is canonical (`fa-wpmcp` vs `fa-wpmcp-server`)?
