# wp cache

## Ability API

- `fa-wpmcp/add-cache` — Adds a value to the object cache.
- `fa-wpmcp/decr-cache` — Decrements a value in the object cache.
- `fa-wpmcp/delete-cache` — Removes a value from the object cache.
- `fa-wpmcp/flush-cache` — Flushes the object cache.
- `fa-wpmcp/flush-group-cache` — Removes all cache items in a group, if the object cache implementation supports it.
- `fa-wpmcp/get-cache` — Gets a value from the object cache.
- `fa-wpmcp/incr-cache` — Increments a value in the object cache.
- `fa-wpmcp/patch-cache` — Update a nested value from the cache.
- `fa-wpmcp/pluck-cache` — Get a nested value from the cache.
- `fa-wpmcp/replace-cache` — Replaces a value in the object cache, if the value already exists.
- `fa-wpmcp/set-cache` — Sets a value to the object cache, regardless of whether it already exists.
- `fa-wpmcp/supports-cache` — Determines whether the object cache implementation supports a particular feature.
- `fa-wpmcp/type-cache` — Attempts to determine which object cache is being used.
