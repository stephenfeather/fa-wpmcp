# wp maintenance-mode

## Ability API

- `fa-wpmcp/activate-maintenance-mode` — Activates maintenance mode.
- `fa-wpmcp/deactivate-maintenance-mode` — Deactivates maintenance mode.
- `fa-wpmcp/is-active-maintenance-mode` — Detects maintenance mode status.
- `fa-wpmcp/status-maintenance-mode` — Displays maintenance mode status.
