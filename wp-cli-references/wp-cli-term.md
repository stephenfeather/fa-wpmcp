# wp term

## Ability API

- `fa-wpmcp/create-term` — Creates a new term.
- `fa-wpmcp/delete-term` — Deletes an existing term.
- `fa-wpmcp/generate-term` — Generates some terms.
- `fa-wpmcp/get-term` — Gets details about a term.
- `fa-wpmcp/list-term` — Lists terms in a taxonomy.
- `fa-wpmcp/meta-term` — Adds, updates, deletes, and lists term custom fields.
- `fa-wpmcp/migrate-term` — Migrate a term of a taxonomy to another taxonomy.
- `fa-wpmcp/recount-term` — Recalculates number of posts assigned to each term.
- `fa-wpmcp/update-term` — Updates an existing term.
