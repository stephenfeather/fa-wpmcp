# wp option

## Ability API

- `fa-wpmcp/add-option` — Adds a new option value.
- `fa-wpmcp/delete-option` — Deletes an option.
- `fa-wpmcp/get-option` — Gets the value for an option.
- `fa-wpmcp/get-autoload-option` — Gets the 'autoload' value for an option.
- `fa-wpmcp/list-option` — Lists options and their values.
- `fa-wpmcp/patch-option` — Updates a nested value in an option.
- `fa-wpmcp/pluck-option` — Gets a nested value from an option.
- `fa-wpmcp/set-autoload-option` — Sets the 'autoload' value for an option.
- `fa-wpmcp/update-option` — Updates an option value.
