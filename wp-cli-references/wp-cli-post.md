# wp post

## Ability API

- `fa-wpmcp/create-post` — Creates a new post.
- `fa-wpmcp/delete-post` — Deletes an existing post.
- `fa-wpmcp/edit-post` — Launches system editor to edit post content.
- `fa-wpmcp/exists-post` — Verifies whether a post exists.
- `fa-wpmcp/generate-post` — Generates some posts.
- `fa-wpmcp/get-post` — Gets details about a post.
- `fa-wpmcp/list-post` — Gets a list of posts.
- `fa-wpmcp/meta-post` — Adds, updates, deletes, and lists post custom fields.
- `fa-wpmcp/term-post` — Adds, updates, removes, and lists post terms.
- `fa-wpmcp/update-post` — Updates one or more existing posts.
- `fa-wpmcp/url-to-id-post` — Gets the post ID for a given URL.
