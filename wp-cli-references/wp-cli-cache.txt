NAME

  wp cache

DESCRIPTION

  Adds, removes, fetches, and flushes the WP Object Cache object.

SYNOPSIS

  wp cache <command>

SUBCOMMANDS

  add              Adds a value to the object cache.
  decr             Decrements a value in the object cache.
  delete           Removes a value from the object cache.
  flush            Flushes the object cache.
  flush-group      Removes all cache items in a group, if the object cache implementation supports it.
  get              Gets a value from the object cache.
  incr             Increments a value in the object cache.
  patch            Update a nested value from the cache.
  pluck            Get a nested value from the cache.
  replace          Replaces a value in the object cache, if the value already exists.
  set              Sets a value to the object cache, regardless of whether it already exists.
  supports         Determines whether the object cache implementation supports a particular feature.
  type             Attempts to determine which object cache is being used.

  By default, the WP Object Cache exists in PHP memory for the length of the
  request (and is emptied at the end). Use a persistent object cache drop-in
  to persist the object cache between requests.

  [Read the codex article][1]
  for more detail.

  ---
  [1] https://codex.wordpress.org/Class_Reference/WP_Object_Cache

EXAMPLES

    # Set cache.
    $ wp cache set my_key my_value my_group 300
    Success: Set object 'my_key' in group 'my_group'.

    # Get cache.
    $ wp cache get my_key my_group
    my_value
